# 📌 Instalación y Configuración de NinjaSDET

**Repositorio:** [GitHub - sergioortiz17/NinjaSDET](https://github.com/sergioortiz17/NinjaSDET)  

## 📋 **Requisitos Previos**
Antes de comenzar, asegúrate de tener instalado en tu sistema:

✅ **Flutter SDK** ([Descargar Flutter](https://flutter.dev/docs/get-started/install))  
✅ **Dart SDK** (Incluido con Flutter)  
✅ **Android Studio o Visual Studio Code** (Para ejecutar el emulador y depurar)  
✅ **Dispositivo físico o emulador configurado**  
✅ **Git** (Para clonar el repositorio)  

### 🔍 **Verifica la Instalación**
Abre una terminal y ejecuta:

```sh
flutter doctor
```

Si ves errores, sigue las instrucciones que aparecen en pantalla para solucionarlos.

---

## 🚀 **Paso 1: Clonar el Repositorio**
Abre una terminal y clona el proyecto:

```sh
git clone https://github.com/sergioortiz17/NinjaSDET.git
```

Luego, entra en la carpeta del proyecto:

```sh
cd NinjaSDET
```

---

## 📦 **Paso 2: Instalar Dependencias**
Ejecuta el siguiente comando para instalar las dependencias del proyecto:

```sh
flutter pub get
```

---

## 📱 **Paso 3: Configurar un Emulador o Dispositivo**

🔹 **Para usar un emulador:**  
Abre **Android Studio** > `Device Manager` y ejecuta un emulador Android.  

🔹 **Para usar un dispositivo físico:**  
Conecta tu teléfono por USB y activa el **Modo Desarrollador** y la **Depuración USB**.

Verifica que el dispositivo esté detectado con:

```sh
flutter devices
```

Si ves el dispositivo en la lista, ¡estás listo para correr el proyecto! 🎉  

---

## ▶️ **Paso 4: Ejecutar la Aplicación**
Corre la app en modo debug con:

```sh
flutter run
```

Si quieres ejecutarlo en un dispositivo específico, usa:

```sh
flutter run -d <ID_DEL_DISPOSITIVO>
```

Para obtener el ID del dispositivo disponible:

```sh
flutter devices
```

---

## 🛠 **Otros Comandos Útiles**

🔄 **Limpiar caché del proyecto (si hay errores):**
```sh
flutter clean
flutter pub get
```

🚀 **Compilar y generar APK para Android:**
```sh
flutter build apk
```

🌐 **Ejecutar en un navegador (si soporta Flutter Web):**
```sh
flutter run -d chrome
```

---

## 📝 **Notas Finales**
- Si tienes errores al correr el proyecto, ejecuta:
  ```sh
  flutter doctor
  ```
  para verificar dependencias faltantes.  
- Asegúrate de tener el **SDK de Android configurado correctamente** en **Android Studio**.  
- **Para correr en iOS**, necesitas **macOS con Xcode instalado**.
